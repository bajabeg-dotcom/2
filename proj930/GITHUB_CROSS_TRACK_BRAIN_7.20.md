# DNA MIDI Studio 7.20 — Cross-Track Brain

This checkpoint adds a lightweight production cross-track planning layer inspired by two vendored Microsoft Muzic components:

- **GETMusic:** track-conditioned infilling / generation concept.
- **Museformer:** fine local attention plus coarse long-range song context concept.

The heavy Fairseq/blocksparse runtime is intentionally not required for the default Windows path. Selected upstream source/reference files and original MIT license are retained under `third_party/muzic_getmusic` and `third_party/muzic_museformer`.

## Runtime behavior

Before MIDI-GPT is asked to REPAIR or REGENERATE a region, `CrossTrackBrain` computes peer-track context around the authorized region and combines it with the 7.10 whole-song symbolic summary. It derives:

- peer roles and local activity,
- onset alignment / rhythmic anchor strength,
- harmonic-support activity,
- target local density,
- MIDI-GPT note-density conditioning,
- sampling temperature and top-p based on context confidence.

Velocity is never read by this planner and remains Factory-only.

## Role relationships

- drums/percussion react to bass and rhythm-section activity;
- bass reacts to drum/rhythm anchors;
- rhythm guitar/power-riff reacts to bass plus rhythm-section density;
- solo/melody remains conservative and is not blindly regenerated by this layer.

## Safety

All 7.03 scope/protected-event gates remain authoritative. Cross-track context can change generation intent, never mutation boundaries.
