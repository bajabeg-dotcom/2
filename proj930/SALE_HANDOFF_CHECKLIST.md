# Sale handoff checklist

- [ ] Identitet prodavca i kupca
- [ ] Dokaz vlasništva nad izvornim kodom i originalnim muzičkim materijalom
- [ ] Završena third-party licencna matrica
- [ ] Dogovoren obim IP prenosa ili licence
- [ ] Popis isporučenih fajlova i SHA-256 provjera
- [ ] Clean-install test na podržanoj Windows konfiguraciji
- [ ] Style Works XT round-trip dokaz
- [ ] Fizički Korg Pa800 rezultat, potpis i priloženi dokazi
- [ ] Rezultat kompletnog 150-song batcha
- [ ] Poznati nedostaci i ograničenja prihvaćeni od kupca
- [ ] Period i obim podrške
- [ ] Garancije, isključenja i ograničenje odgovornosti
- [ ] Backup i recovery procedura predati kupcu
- [ ] Konačni acceptance zapisnik potpisan

Ovo je tehničko-operativna lista, ne pravni savjet niti zamjena za ugovor koji pripremi kvalifikovani pravnik.
